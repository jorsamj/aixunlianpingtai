# 多视觉模型标注 P0：需求、设计、修复与验收

日期：2026-11-05。基线：42.24.532 / 84e3047f23a6423ea4722398925a76ab9294d2c6；本地与远端已核对，开始时工作区干净。唯一开发分支 feature/external-algorithm-publishing。

## 需求与设计

1. 共享解析器使用显式坐标范围及顺序，将模型坐标统一为原图像素 XYXY；拒绝非有限、反向、越界和未知几何。不能仅按模型名或数值大小选择新合同。
2. 模型配置复用原管理入口；高级字段同层折叠。旧任务保留冻结合同，不批量改写历史配置。新增合同进入现有模型快照修订哈希。
3. 提示词继续使用已有模型默认、模板版本和任务覆盖；平台末尾追加受控结构合同。人员业务示例可编辑，不在检测算法中硬编码阴影、门框等规则。
4. 审核沿用原 CandidateStore，按单图查看有限结构候选、几何、转换和过滤计数，不存原始响应自由文本或密钥，不新增 GT。

## 已有能力，避免重复开发

annotation_runtime 已实现无密钥模型快照、修订校验、提示词模板版本及任务覆盖。annotation_task_service 已实现阈值、分类 NMS、候选独立持久化与任务 generation 围栏。沿用这些 Owner；不新增任务中心、提示词中心或缓存。

## 确认的缺陷

原 parse_candidate_response 仅当 x2>width 或 y2>height 才尝试 0～1000 转换。1920×1080 图片上的合法千分坐标会被当成像素，导致定位缩小偏移。此源码反例证明平台缺陷，但不是两款实际模型的原始输出证据。

## 验收边界

尚未获得用户真实异常图片、Gemma/Qwen 原始响应和部署服务访问证据。不得宣称现场识别准确率提升、误检漏检消除、Ollama/vLLM 真实通路通过。合成坐标单测和浏览器隔离夹具只验证平台合同及界面。

GPU A800/4070、真实弱光/黄色衣服/门框/阴影案例、模型内部 resize 行为仍需现场验收。不能由模型自报 confidence 计算可信准确率。无部署、无正式 GT 修改、不重跑历史标注。

## 配置验证与并发修复

验证使用上传样本，只有明确人工确认才能标记当前样本已验证，不承诺模型准确率。服务端随机回执绑定配置独立UUID、样本哈希，15分钟过期；编辑配置立即作废。原存储锁串行化写入，迟到成功/失败不能覆盖新配置或新验证。env:凭据引用与原任务运行保持一致，不输出密钥。

人员示例只存于可编辑提示词，不改变标签判断算法。尚未支持原生自由数组格式，UI只列现有JSON boxes协议；Gemma/YXYX或Qwen/XYXY均需按实际返回确认，不能仅因模型名称自动启用。

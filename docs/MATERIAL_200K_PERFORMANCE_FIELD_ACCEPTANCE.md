## 测量与判定

- 冷和热分组报告。冷组记录实际冷的是浏览器缓存、应用缓存、数据库或缩略图，使用新浏览器上下文或自然未命中的等价样本。热组记录预热条件和命中依据，复用相同过滤、排序、页大小与修订。现场不强制清缓存、重启服务或改 DB。
- 每个可重复的只读场景按约定的样本量采集，建议每组至少 30 次可比样本。记录样本量、P50/P95、失败率、超时数、请求数、响应字节与可见内容就绪时间。耗时分开记浏览器排队/连接、TTFB、下载、解码与主线程渲染。长任务与资源峰值记录时间区间，失败保留原始计数。写入任务记录进度、处理量、失败/重试与磁盘释放，不能混进查询 P95。
- 现场开始前签认同环境基线及 P95、超时率、内存、磁盘和并发预算。下表的“达标”指功能断言成立且在该预算内。未获签认阈值、样本不足或取不到关键数据时标为 `NOT VERIFIED`，保留原始观测值。
- 异常证据统一带时间/时区、版本 SHA、脱敏项目和请求/任务 ID、修订、视口及测试条件。归档脱敏 HAR、Chrome trace 和服务器分段指标。删除授权头、Cookie、原图、签名 URL 和内网地址后再共享。

## 场景

| 项目与目的 | 前置条件与操作 | 预期与通过标准 | 异常证据 |
| --- | --- | --- | --- |
| M01 素材库冷查询，确认首屏有界 | 选自然未命中样本，从导航进入素材库，固定查询、页大小及 Chrome 视口。 | 首屏数据与筛选正确，分页体量可控，查询及首屏 P95 在冷组预算内。 | 缓存命中信息、请求耗时和响应字节、首屏截图。 |
| M02 素材库热查询，确认复用与新鲜度 | 预热后重复 M01；用测试项目修订变化对照再打开。 | 热组达标，修订变化后显示正确真值，缓存命中有证据。 | 热组统计、命中来源、修订及实际响应。 |
| M03 分页，确认深页准确与响应 | 固定排序及筛选，执行首、中、尾页和快速返回；记录总量未知时的导航行为。 | 各页稳定且不漏重，快速切页不显示过期响应，深页耗时达标。 | 页码、排序参数、连续页 ID 摘要、失败请求时序。 |
| M04 缩略图加载，确认可见范围优先 | 选有冷/热缩略图和可控慢对象的页，滚动并离开。 | 可见图按需加载，失败局部可重试，离开后无旧图污染，图片与请求预算达标。 | HAR/瀑布图、缓存命中、图片大小和浏览器解码段。 |
| M05 图片详情，确认按需取图 | 混用高分辨率、标注图及可控失败图，打开、缩放、切换、关闭和重入。 | 详情与当前 ID 一致，原图/标注按需加载，失败有反馈，交互与资源达标。 | 图片尺寸、当前 ID、截图、trace 与请求字节。 |
| M06 跨页批量选择，确认冻结范围 | 在测试项目跨页勾选及排除，另做全筛选引用对照，刷新并查看提交前摘要。 | 计数及样本 ID 可对账。大范围选择使用现有冻结引用，不下发全量 ID；范围变化显式提示。 | 选区引用、排除摘要、提交体大小及前后计数。 |
| M07 负样本池批量操作，确认结果可恢复 | 用专用池和有限候选，分批处理，模拟可控部分失败并在原入口重试。 | 逐批回执、成功和失败可查；重试不重复转池，不改变选区外状态，耗时达标。 | 批次、回执、候选与池计数、重试轨迹。 |
| M08 素材审计，确认长任务可观察 | 用只读审计入口、已知重复/缺失样本及对照，记录后台进度和终态。 | 进度、问题分类与基准样本相符，结果分批可查，前台可继续操作，审计预算达标。 | 任务 ID、阶段进度、问题列表、处理速率和日志。 |
| M09 增量复核，确认正确性与成本 | 测试项目先有完整审计，记录 revision；做授权的单批变化，再做无关修订对照。 | 支持的增量范围结果与全量对照一致，无关变化按现有合同回退；记录实际访问量。 | 前后 revision、变更范围、增量/全量差异和耗时。 |
| M10 ZIP 导入，确认进度与数据边界 | 用批准的 ZIP 集覆盖原图、带标注及受控失败，记录压缩/展开量；在独立环境使用原入口导入。 | 批次及逐项结果可对账，既有取消/失败恢复有效，GT 遵循原确认流程，资源峰值达标。 | ZIP 哈希、成员统计、上传/扫描/确认阶段、回执和资源曲线。 |
| M11 训练素材筛选，确认首屏与准入信息 | 选有历史、标签与负样本的算法，进入原选材界面，切换条件并选样；停在预检。 | 当前筛选准确，首屏、分页和摘要达标，未知总量可翻页，预检保持真实阻断。 | 筛选/分页响应、标签摘要、请求阶段和预检原因。 |
| M12 浏览器主线程卡顿，定位渲染成本 | 三视口各录制首屏、翻页、勾选、详情和关闭，记录设备/CPU 条件。 | 在交互与长任务预算内，表单或选择输入能及时响应，不出现持续无反馈。 | Chrome Performance trace、长任务数/持续时间、操作到下一可见帧耗时。 |
| M13 页面切换响应，确认生命周期 | 打开有请求在途的素材页，再快速切换其他页、返回并重复。 | 当前页面及时就绪，陈旧结果不会回写，已离开页面的请求/定时器按原机制收束。 | 导航时间线、请求取消/完成标记、重复请求计数和截图。 |
| M14 网络请求超时，定位实际等待 | 用隔离浏览器延迟/中断对照，生产只读取既有正常及失败观测。 | 可区分连接、TTFB、响应体和应用等待；失败能反馈与重试，恢复不串页，正常组超时率达标。 | HAR 分段、请求 ID、代理与应用耗时、超时错误及重试结局。 |
| M15 服务器内存，确认峰值和回落 | 有授权只读监控，记录安静基线、只读操作和隔离写入场景的前/中/后 RSS，能取时附 USS。 | 区分 Web/Worker 及子进程峰值，在预算内，重复操作后可回落或趋稳，无 OOM。 | 采样频率、进程树、内存曲线、并发/任务时线。 |
| M16 数据库查询，确认读路径与计划 | 复用现有性能指标或只读镜像，采集首/深页、筛选与标签摘要的查询及计划。 | 查询/连接数量、耗时和锁等待满足预算，读取范围与预期一致，无大范围重复扫描证据。 | SQL 指纹、脱敏计划、行数、查询计数与锁等待。 |
| M17 磁盘占用，确认暂存与回收 | 记录 DB/WAL、缩略图、ZIP 暂存和产物存储基线；用独立项目观察完成/失败/取消后。 | 峰值与剩余容量达标，按既有清理规则回落，原图和引用产物仍可用。 | 分目录增长/回落、可用空间、回收观察窗、对象引用抽查。 |

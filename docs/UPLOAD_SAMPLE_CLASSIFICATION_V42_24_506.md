# 42.24.506 上传素材正负样本分类与训练选材

日期：2026-11-03；分支：`feature/external-algorithm-publishing`；基线：42.24.505。

## 本次实现

- **普通图片（含单图与多图）**：上传完成、回执核验之后，在「本次上传图片」选择待处理图像，再明确选择「正样本／负样本」。正样本多选**待标注标签**；负样本多选**负样本池分类**并可创建分类。选择完成才能开始清洗或直接入标注。负样本直接入池，不自动打开 GT 标注器。
- **ZIP**：完成上传、校验、扫描后，**即使无外部标签，也等待确认素材类型**。若含 YOLO／COCO／VOC 外部标注，原标签映射仍需人工确认；正负样本选择与正式标签映射彼此独立。确认后保持原 ZIP 后台导入 FIFO 与冻结语义。导入提交后按新图 ID 批量附加意图或池分类，失败以 `report.upload_classification_status=pending` 和警告记录，保留已提交原图与 GT。
- **数据隔离**：正样本选择只保存 `upload_intended_label_codes`，**不生成正样本 GT／标注框**；负样本选择只写既有 `negative_pool_members` / `negative_pool_links`，**不清空原标签、不抹掉原标注、不自动断定训练负样本为审核真值**。无效／停用标签或分类由服务端拒绝。
- **训练选择器**：沿用已实现的训练素材选择器「素材范围 → 负样本池」和「负样本分类」筛选；负样本池中的素材可与其他素材合选，训练前保持已有负样本证据复核及「首次训练不得纯负样本、仅允许已有模型继续训练」限制。本批不改变 GT 准入、模型血缘隔离及选材快照 Owner。

## 验收建议

1. 上传一张无框图片，选择正样本 `fire`，检查仅保存待标注意图，并打开标注器；正式 GT 直到人工保存框后才变化。
2. 上传一张原本带 `blue` 标签的图片，选择负样本分类 `背景干扰`，检查负样本池成员与分类已写入，原 `blue` 标签／框未改变。
3. 分别上传无标注 ZIP、带标注 ZIP；确认都先停在正负样本选择，前者无空白标签映射表，后者保留外部标签映射；导入后查池成员／待标注意图／原 GT。
4. 在训练素材选择器选择「负样本池」并按分类筛选，验证可选中、可预览、能进入训练草稿；纯负样本首次训练仍被拦截。
5. 多批次、失败重试、切换项目、取消 ZIP、部分上传失败，以及分类/标签在等待阶段被停用时的错误提示。

## 验证边界

单元与接口回归覆盖 metadata 不影响 GT、项目标签有效性、负样本分类、跨批次上传回执与负样本不自动开启标注器；ZIP 前端回归覆盖新的待确认状态。**本地回归不代表生产对象存储、真实浏览器、正式训练 GPU 或现场验收**。不执行生产数据迁移、清理、部署；后续需对精确代码 SHA 单独核验 CI。

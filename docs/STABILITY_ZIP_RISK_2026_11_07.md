# ZIP sidecar 内存与取消复核

基线为 42.24.561 / `fc38666004168104c1d9ed1356d690fb46218561`。本轮用隔离样本确认了扫描内存放大和单成员取消等待，结论是记录风险，保留现有上传、标签映射、GT 事务和任务恢复合同。

## 测量方法

- Windows 11、CPython 3.12.7 x64、psutil 7.2.2。每个样本启动独立 Python 进程，导入基线 `app.py` 后调用原 `v19_scan_zip`。数据根指向本轮专用临时目录。仅调用扫描函数，计时排除应用导入、夹具生成、网络与磁盘提取阶段。
- 每包含 1 张真实 64×64 JPEG。COCO JSON 含合法类别、图片和唯一 ID 的密集框记录，VOC XML 含完整尺寸及密集框，YOLO TXT 含同一图的合法框行，YAML 含合法 `names` 和用于制造体量的可选描述。正常测量使用 Store，读取取消另用 BZIP2。合成标注特意集中在一张图上，数字反映这些结构的资源消耗。
- 内存采用进程 `peak_wset` 减去扫描前工作集。并发启动两份相同 COCO 扫描，父进程按 2 ms 请求间隔采样存活子进程的工作集之和。工作集可能含共享页，采样可能错过瞬态峰值。
- 取消测量仅为原读取与解析调用加计时包装。子进程在实际调用开始时写标记，独立父进程观察到标记后写停止标记。原 progress callback 看到标记时抛 `_V19ImportStopped`。用调用开始、结束时间验证请求确实落在测量区间内。未用延时替代读取或解析。
- 使用基线默认 `MC_ZIP_*`。单成员声明上限 128 GiB、总量 512 GiB、压缩比 1000。测试侧未调整合法输入上限。

COCO 大样本观察到两次整成员 `ZipFile.read`，三个 JSON 解析调用分别耗时 128.5、139.0、188.9 ms。VOC 大样本也有两次整成员读取，三次 XML 解析分别耗时 235.1、207.6、345.8 ms。第三次解析来自独立的类别样本展示，读取走该模块的 `ZipExtFile`。扫描阶段分别生成外部类别、识别是否存在标注证据、构建类别样本。多个解析结果可能同时驻留。类别样本读取原有 32 MiB 上限，扫描后段原有 32/64 MiB 判断，这两者均晚于扫描首次整成员读取。YOLO TXT 的 `.splitlines()` 也会一次建立行列表，YAML 的大描述会进入 `safe_load`。

对应位置见 `app.py:15722`、`:15768`、`:15797`、`:15839`、`:15886`、`:15898`、`:15909`、`:15931` 和 `platform_core/zip_label_samples.py:15`。正式导入另有读盘解析入口 `app.py:14739`、`:14871`、`:14984`，本表只计扫描阶段。`app.py:16831` 按任务键去重后台 finalize，源码中该入口没有跨任务总量门禁。两进程测量提供叠加量级，实际单服务多线程调度和部署容量仍需现场数据。

## 单成员取消与恢复

| 实际发送取消的区间 | sidecar（MiB） | 标记到扫描停止（ms） | 观察 |
| --- | ---: | ---: | --- |
| COCO BZIP2 整成员读取 | 23.62 | 761.4 | 本次读取用 117.4 ms，随后 JSON 解析仍执行 418.3 ms |
| COCO JSON 解析 | 11.75 | 815.8 | 首个解析已开始，原流程还执行了后续解析才抵达检查点 |
| VOC XML 解析 | 12.00 | 571.9 | 首次 XML 解析用 238.8 ms，后续检查点停止 |
| YOLO YAML 解析 | 6.00 | 1,239.0 | 单次 YAML 解析用 1,239.3 ms |

原扫描 callback 在成员循环和阶段边界执行，约 0.5 秒节流无法给单个 `read`、解析器调用或同一成员后续统计提供取消时限。这些测量止于原扫描异常返回。HTTP 接收取消、持久状态更新和清理完成的耗时另算。

原提取路径按 1 MiB 读取，在块边界检查停止和磁盘空间，CRC/长度验证后以 close＋replace 发布本次成员。后续成员中止时，本次 `.part` 清除，任务级清理由原停止流程负责。预提交停止能回滚已暂存素材，进入正式提交后沿原围栏拒绝取消。multipart `merging/validating` 状态由原任务读取触发重调度，原取消清理失败可重试。测试确认这些路径，未模拟主机 OOM 或真实磁盘耗尽。

在隔离临时数据上运行以下基线回归，**34 项通过，5.74 秒**。范围包括真实坏 CRC、模拟磁盘不足和实际长度超限、提取内取消、本次 part 清理与旧目标字节保全、部分已暂存时停止、取消重试、终态保护以及中断 finalize 恢复。

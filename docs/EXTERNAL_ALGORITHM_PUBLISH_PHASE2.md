# 外部算法平台 Phase 2：训练成果发布

本阶段在 Phase 1 主数据同步基础上，将本平台训练/转换产物发布到已配置的对象存储，并向新畅联登记算法版本与权重文件。

## 已实现

- 训练成功且模型产物完整性校验通过后，可标记为待自动发布。
- 发布前等待该算法版本关联的模型转换任务结束，运行中的转换不会被提前发布。
- 从既有 `algorithm_versions` 与 `deployment/jobs` 发现模型制品，不复制出第二套本地生命周期。
- 复用既有 Storage Provider（local / OSS / S3 / MinIO / remote）上传发布制品。
- 发布制品使用内容 SHA256 生成稳定对象键；持久化后使用 `source_sha256` 校验，兼容发现阶段的 `sha256` 字段。
- 上传后校验文件大小；远程存储提供 SHA256 时同时校验哈希。
- 使用稳定的平台下载 URL 向外部平台登记权重文件，不向新畅联暴露本机文件路径。
- 新畅联算法版本创建、权重登记均支持反查恢复，避免请求超时后盲目重复创建。
- 本地使用 SQLite 持久化 publication / artifact / external version id / weight id / 错误与重试状态。
- 提供手动“重新同步”，自动重试有退避窗口，结果未知时不会自动重复创建。
- 平台对接页增加训练成果发布配置与发布记录查看。

## 发布边界

- 仅外部算法主数据（`source_type=EXTERNAL`）进入该发布链路。
- 本地算法仍维持本地生命周期，不自动推送到新畅联。
- 转换目标必须显式映射到新畅联算力环境/芯片编码后才会发布。
- 发布失败不会改变本地训练版本的可用性，也不会删除已有训练/转换产物。

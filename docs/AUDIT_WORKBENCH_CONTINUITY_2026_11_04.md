# 素材审计连续操作治理（阶段 F）

## 需求及边界
同一审计版本返回问题列表时保留分页、已选项、筛选、滚动和已有图片 DOM；返回不能触发审计 POST。素材/GT 发生变化仍由服务端严格拒绝旧计划，不削弱冻结、历史或 Test 保护。复用原 `state.materialIntegrityAudit47`，只保留当前审计的一份已加载列表 DOM，不新增请求中心或数据缓存。

## 本批实现
- `static/app.js` 的原完整性审计 Owner 在进入详情/治理预览时暂存当前列表节点和滚动，返回同步恢复节点，不重新请求 latest、第一页和治理摘要。
- 恢复后仅查询同一审计 `groups?limit=1` 核验 stale；失败明确显示版本暂不可核验，真正写入仍经过原冻结计划/执行围栏。
- 新审计清除旧列表引用；项目、任务、过期状态限制恢复，防止跨项目旧节点复用。
- 真实 Chrome 暴露原预检查按钮仅在 isConnected 时结束 Loading；现在仅对当前审计保留的离线节点也恢复按钮，防止连续第二次操作卡住。
- `smart-material-audit.css` 中完整性工作台采用平台 Token、克制边界、Focus/Hover、触控尺寸与 reduced-motion，不引入表格或图片组件。

## 阶段证据
- 新 Node 行为/集成守卫先失败后修复；原完整性测试合计 38/38 通过。
- 新 Chrome 十次预览/返回，原 DOM 身份及选中保留；latest 只读一次，审计 POST 为零，定向 1/1 通过。
- 现有实际 Worker 冻结范围/删除/审计复用回归已通过：API 63/63、Chrome 原工作台及新增返回测试9/9。后续新增并发/跨阶段回归另列。
- 测试内 200000 仅为摘要夹具，不是 20 万真实索引，不构成规模性能验收；真实性能和多视口截图在浏览器报告中单独记录。

## 已存在机制与后续边界
`material_batches._reuse_material_integrity_after_retirement` 已按正式退休回执、Material/Annotation 修订等决定增量复用，证据损坏回退完整审计。当前批量冻结计划已有 skip_reasons 和预览中文说明，完整性与 Smart Audit 不能混为同一写入 Owner。通用 GT 变化仍明确失效回退原完整审计；不能把没有证据的变化视为退休增量。

## 接续：持久跳过、恢复与连续处理
- 原审计 SQLite 增加可选 `group_review` / append-only `group_review_events` 辅助工作流表；只在用户写操作时初始化。issue_items/groups 和正式 GT 不因跳过改变。
- `/audits/{id}/reviews` 复用项目/任务鉴权、可信 actor、原 Material/Annotation lifecycle fence；仅允许已存在且未过期问题组、每批100、每组修订CAS。UI按已选行的修订分桶串行提交，遇冲突显示部分可能已保存，要求核对，不能覆盖别人的处理。
- 问题列表按待处理/已跳过过滤，计数与相同过滤一致；跳过原因结构化，支持恢复所选。详情支持下一问题、跳过并下一条；只有受影响的卡片补丁，不重建其余DOM。
- 用户跳过的组不进入后续治理计划；计划在读取任何组状态前冻结操作修订，执行前和最终任务发布围栏内再次核验，避免“预览后跳过仍被删除”。确定性交错回归在keeper选择期间写入skip，旧计划执行409。
- 已完成删除提供“继续处理问题·复核本次变化”，调用原退休回执复用路径，成功后在仍归属当前进度层时自动返回新问题列表。
- 退休增量使用原SQLite backup保留未受影响组的工作流证据。新增真实API回归：跳过B→治理A→退休增量→B仍保持原因与修订。未知GT变化仍不能复用旧审计。

## 视觉与性能证据
- 实际截图检查后将大统计卡改为三个紧凑指标，筛选两列，一级操作仅全选本页/预览所选/批量去重；低频全筛选/清空/跳过/恢复/智能建议/GT批审收到更多操作，长保护说明默认折叠。
- `docs/artifacts/audit-workbench-20261104/` 保存1440/1280/768/390截图及真实Chrome十次返回样本。返回P50/P95以 `return-timings.json` 为准，约数十毫秒；仅25个已加载问题组，不声称20万DOM。
- 独立SQLite实际插入10k/100k/200k问题组+索引，API每页25，首次/深游标/类型筛选均测12轮；200k温P95约87/120/151ms（确切值见 `sqlite-paging-scale.json`）。查询计划命中 `ix_material_integrity_groups(issue_type,group_key)`。首次请求不等于OS冷缓存；不含原图、OSS及生产并发。
- 未引入Tabulator/AG Grid/图片组件：当前服务端游标+25组DOM已满足此隔离查询/返回目标，新增依赖不能解决原Owner反复销毁和预览按钮结算问题；不宣称完成生产20万原图全审计性能验证。

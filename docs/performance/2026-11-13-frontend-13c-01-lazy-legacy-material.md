日期：2026-11-13；唯一分支：`feature/external-algorithm-publishing`。

## 已通过的前置验收

13B-03 精准回归修复 `a740338dd124402f0a0d1a6284cdff8edf93b5c4` 对应 **21/21 GitHub Actions 成功**，包括 Frontend Runtime Stabilization 所属单元与 Chrome 分片。13B 前三项代码已验收，但不代表 A800/4070 生产部署验收。

## 实际审计

`static/main.mjs` 首屏有 65 个顶层静态 import，包含只用于“旧素材兼容迁移”专用页面的 `static/modules/legacy-material-compatibility.js`（约 15 KB 源码）。正常总览、算法列表、素材库、训练任务无需请求或解析该模块，其扫描/预览/应用及 IndexDB 检查逻辑原本已经封装在原模块，适合低风险延迟加载。

## 13C-01 最小变更

- 将该模块的静态 import 移出 `main.mjs`，在原 `registerPageOwner('旧素材兼容迁移')` 中执行原模块的 `import()`，不改原 scan/preview/apply 代码、合同或 GT。
- 首次进入才加载，成功后复用已加载模块；同时使用现有 `NavigationStability.action()`、项目 ID 和渲染代次阻止异步模块载入后覆盖其他页面/项目。
- 失败时仅在仍拥有页面的情况下显示局部重试（重新进入当前页面）入口，不抛出未捕获错误，也不额外开启轮询、全局监听器或请求所有素材。
- 仅更新 HTML 三入口静态资源一致的数字缓存版本至 `42.25.598`，不变更正式 `VERSION.txt`。
- 新增静态作用域防回退测试、已在 CI 中纳入的真实 Chrome 页面首次加载与重复进入／退出加载竞态测试，保持原有旧素材扫描、暂停和重试浏览器测试。
- 本轮没有做多页面同时按需拆分，避免扩大风险；`app.js` 1.3 MB 的存量大小未减少，不能把这项试点宣称为首屏总体耗时明显改善。

## 验收及退出

只能声称“首屏少拉取该模块一份”这一源码可核查事实；具体请求数量及性能差异须以浏览器回归和准确提交 CI 为准。不得访问生产 A800/4070、合并 main、创建 Release 或改动训练/清洗/正式 GT。CI 失败则仅对实际失败项修补。

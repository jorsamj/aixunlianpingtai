## 尚未完成及为什么未盲改

1. **旧训练任务 GET 重投影（P0，风险高）**：`list_jobs` 可调用 `_v48_dispatch_training_queues`，`sync_jobs_index` 在 GET 中读历史并可能写索引/归档旧版本；`v53/bootstrap/snapshot` 的活跃任务覆盖亦依赖它。这里涉及旧任务执行调度和版本归档，直接删除会导致遗留任务无法调度。应先为旧任务建立独立维护触发者/调度器、显式回填，再切到纯只读索引；需要隔离真实旧样本做兼容验收。
2. **素材页状态数量/角色分页、SQL `%LIKE%`（P0，待量化）**：现有分页与候选选择索引不可随意替换。请在同筛选条件下采样 48 张与大素材库，收集数量查询 SQL 和磁盘计时后再确定索引/摘要策略。
3. **代理连接排队、畅联云同步、GPU 检测真实耗时（P0，缺生产证据）**：须用同时间脱敏 HAR 与 Web 采样日志分解浏览器排队、服务器业务、锁和外部 HTTP；未增加任意超时时长或并发压测。
4. **训练临时素材副本与溯源不可见（P1）**：未删除生产文件，也未触发迁移或数据重建；须另行开展只读候选清单和安全归属核验。

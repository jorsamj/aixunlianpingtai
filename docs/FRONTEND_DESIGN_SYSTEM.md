# 畅联云前端设计规范

独立 Vue 应用通过 `frontend/src/app/style.css` 提供主题与 Element Plus 公共覆盖。继续使用本地字体和已有组件。交互设计参考键盘焦点、状态反馈及主题组织方式。 [Arco Design Vue](https://arco.design/vue/en-US/docs/pro/start) · [Semi Design](https://semi.design/zh-CN/)

|主题变量|值及用途|
|---|---|
|`--workspace-ink` / `--workspace-muted` / `--workspace-subtle`|`#171717` / `#52525B` / `#686872`，正文、说明和辅助文本|
|`--workspace-surface` / `--workspace-page` / `--workspace-hover`|`#FFFFFF` / `#F7F8FA` / `#F1F2F4`，内容、页面和交互背景|
|`--workspace-line` / `--workspace-accent`|`#E4E4E7` / `#242424`，分隔线和重点动作|
|`--workspace-radius` / `--workspace-gutter`|`8px` / `16–24px`，内容边角和页面留白|

- 页标题约 20–24px，区块标题 16px，正文 14px，辅助文字 12–13px。默认控件使用 Element Plus，普通控件圆角 6px，弹窗圆角 12px。键盘焦点有明确描边。
- 侧栏保留现有菜单和顺序。页头分开项目上下文和会话操作。表格强调行分隔和悬停，状态色用于业务结果。
- 弹窗区分标题、可滚动正文与操作栏。审核入库按范围、执行、完成或待核验展示，进度仅显示已核验的服务端数量。结果未知沿原请求查询。
- AI 审核在桌面保留三栏，紧凑视口以侧边检查面板容纳同一套操作。缩略图保持完整图像比例，原图放大和标注框继续使用既有组件。素材库优先展示图片、状态及人工标注。算法库保持卡片并分组呈现版本、训练和指标。
- 训练表单按原业务分组，报告复用 ECharts。具体阈值、请求、证据和旧入口交接状态见功能矩阵。

## 状态与共享组件（2026-11-26）

- `frontend/src/components/TaskStatusTag.vue` 统一总览、质量中心与训练任务的任务状态用词与色调。仅成功、警告、失败使用语义色，其余为中性标签；取消请求与实际取消分别呈现；`PARTIAL_SUCCESS` 使用警告语义，不与成功同色。页面不再各自维护状态色映射。
- 审核状态以 `role="status" aria-label="审核状态"` 暴露，图像名称保留独立标题；状态与图片身份分离，便于键盘与读屏定位。
- 耗时只表达服务端证据：终态显示“终态 X”，运行中显示“自然 X”（含等待与暂停，非有效训练时长），排队显示“尚未开始”，终态缺结束时间显示“缺少结束时间”，不使用本地时钟推算。
- 资源与交付页统一使用“概览指标条 + 分组面板 + 语义状态标签”的结构；技术字段（API 路径、原始数据）收进折叠区或详情，不作为首屏主体。
- 算法库卡片、筛选条、版本面板与只读事实区改用 `--workspace-*` 令牌，历史硬编码灰阶与 10px 圆角已清理为 8px 卡片圆角；卡片主操作使用 `primary`，版本行原流程链接降级为次级文字样式，避免与原生入口并列竞争。
- 状态标签只表达业务结果，不承载状态机；进度、回执和资格仍以服务端事实为准。
- 指标可比性：最佳版本只在同基准、同协议且输入绑定已验证的评测之间比较；不同口径分组展示、各自标注“该口径版本数”，并说明统计窗口（例如“仅最近 40 / N 个版本，不是全历史最佳”）。当前版本、最新创建版本与最佳评测版本是三项独立身份，可同时成立，不使用分页首行推断。
- 工作台状态：任务与素材概览只使用互斥业务分类（取消请求属于“正在停止”，不计入失败或已停止），未读取显示 `—` 而不是 0，当前页统计标注“本页”。批量操作沿用原资格投影与既有回执，不在前端重新推导权限。
- 转换与交付页面使用同一套黑白灰令牌，并在页面内明示“转换结果 → 结构验证 → 数值与检测框一致性 → 板端验证 → 交付准入”的证据分层。

# ZIP 全流程取消、标签统一与缓存优化设计

## 目标

在现有 v19 ZIP durable runtime、MultipartRepository、导入 Worker、标签映射 Review、NavigationStability、PageRequestScope 与 PollRegistry 上完成三项闭环：

1. 尚未进入不可撤销提交边界的 ZIP 任务可随时请求取消，并只清理该任务拥有的临时资源；
2. 标签统一弹窗改为“任务摘要 + 左侧映射 + 右侧真实样本 + 固定操作区”的企业级工作台；
3. 修复启动就绪竞态，并减少 ZIP 状态恢复和页面回访中的重复请求，不新增缓存或轮询 Owner。

## 方案选择

### 采用：扩展现有 v19 取消合同

- `uploading/paused` 继续由 `ZipMultipartRepository.cancel()` 清理分片。
- `merging/validating/selecting/queued/running` 通过同一个 job 取消入口持久化 `cancel_requested`。
- 合并、校验、扫描和 Worker 在已有进度回调/阶段切换处检查取消。
- `DB_COMMIT` 及终态拒绝普通取消；不伪造成功，也不删除已提交正式数据。
- 任务目录清理按 job ID 和固定白名单执行，保留 `job.json` 最小审计记录。

### 未采用

- 把所有 ZIP 前置阶段迁移进 TaskRepository：会形成大范围迁移并制造第二套兼容路径。
- 仅前端隐藏任务或直接删除目录：无法保证后端停止及资源归属安全。
- 为页面性能建立新全局缓存管理器：会与现有页面 Owner、TTL 和 PollRegistry 竞争。

## 取消状态与安全边界

沿用现有 `cancel_requested`、`cancelled` 和终态合同。请求必须幂等：重复请求返回当前真实状态。取消服务按状态分派：

- 上传/暂停：终止浏览器 XHR，服务端 tombstone 会话并删除本任务分片。
- 合并/校验/扫描：记录取消意图；后台回调观察后停止，删除 `source.zip`、扫描投影和解压目录。
- 等待标签确认/排队：同步标记取消并清理未提交 ZIP/扫描证据。
- Worker 解压/解析：现有 stop fence 触发 batch rollback；确认没有 Material 正式索引后再删除源 ZIP。
- 原子提交：拒绝取消。提交结束后只能走独立、带引用检查的撤销功能，本轮不实现危险批量删除。

新建正式标签继续发生在用户最终确认时。若标签已经通过 canonical API 成功创建，它是项目正式标签，不由 ZIP 临时目录拥有；取消不会删除它，以避免误删其他任务或素材正在使用的标签。UI 必须对此给出真实说明。

## 标签统一 UI

- 顶部只展示文件名、图片数、原始标签数、映射完成数和当前状态。
- 主体为双栏：左侧标签映射行；右侧当前标签的真实样本、标注框和样本切换。
- 映射行提供已有标签选择、显式新建状态和“使用此原始标签”。
- “一键使用原始标签”只形成映射草稿，不创建标签、不启动导入。
- 底部固定操作区：取消本次导入、一键使用原始标签、确认标签并导入。
- 映射不完整时主按钮禁用并显示未完成数量；1366×768 下主体内部滚动，按钮不消失。
- 每个 ZIP 的 review state 继续按 job ID 独立保存在运行时内存；切换任务不互相污染。

## 启动与缓存

- 浏览器测试和真实入口都等待既有 `window.__clInit()` / 项目身份就绪，不创建第二个 readiness 状态。
- ZIP reconcile 首次列表 GET 后，仅在真正提交 start 导致服务端状态变化时进行第二次 GET；纯观察、等待确认和页面回访只读一次。
- 已结束 ZIP 停止高频轮询；活跃任务仍由原 PollRegistry Owner 获取真实服务端状态。
- ZIP 完成仅失效标签、素材页及质量统计；取消只清理对应 job 的前端任务缓存。
- 其他页面继续复用当前项目级 TTL、single-flight 和分页缓存，不缓存敏感内容或完整素材池。

## 错误与竞态

- 取消与完成并发时，以服务端锁内读取的最新状态为准；完成后取消返回冲突。
- 迟到的合并/扫描线程在写回前检查取消，不能把 `cancelled` 覆盖为 `selecting`。
- 切换项目后，旧项目响应不得写入当前项目；继续使用现有 request scope 和 project identity fence。
- 清理失败将任务标记为失败并保留资源和审计证据，绝不继续扩大删除范围。

## 验收

- 高价值 API 测试覆盖：等待确认取消、运行中取消、提交阶段拒绝、幂等、相邻 ZIP 隔离、归属文件清理。
- 前端测试覆盖：统一取消入口、批量独立性、标签草稿/固定操作区、ZIP reconcile 单次 GET。
- Real Chrome 覆盖：启动 ready 后多 ZIP 上传、标签确认及取消。
- 运行现有 ZIP、标签、训练输入完整性与页面加载性能测试；记录修改前后请求数量。
